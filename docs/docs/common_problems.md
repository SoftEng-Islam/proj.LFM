# Common Problems

**NB: For common problems during installation, please open [here](/docs/install/#common-problems)**

<details>
<summary>

### Opening folder like `Documents`, `Desktop`, `Downloads` make Files crashes

</summary>

Disable the [`Extract exe file icon and make it as preview`](/docs/guides/setting/#extract-exe-file-icon-and-make-it-a-preview) setting.

Also, please make sure that windows defender isn't blocking Files from accessing your documents.

</details>

<details>
<summary>

### Files is unstable after installing it

</summary>

Simply restart, Files will fix itself, if it doesn't, please address an issue [here](https://github.com/softeng/Files/issues/new).

</details>
