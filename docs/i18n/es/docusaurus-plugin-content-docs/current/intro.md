# Files

![Demo](/img/docs/themed-Files.webp)

## Resumen

Bienvenido a Files, un explorador de archivos gratis y de código abierto (FOSS).

Files es un moderno explorador de archivos construido desde cero para ser totalmente personalizable para adaptarse a las necesidades de 2022. Siempre, Files es una aplicación multiplataforma alimentada por la web que está siendo envuelta usando el framework [Tauri](https://tauri.studio) en el que se puede ejecutar Files en Windows, MacOS o Linux sin tener muchos problemas. Algunas de las características de Files son:

- Tiene un aspecto moderno
- Fácil de usar.
- [Multiplataforma](https://Files.space/)
- [Vista previa](https://Files.space/docs/guides/operation/#preview-file), incluso para videos!
- [Personalizable](https://Files.space/docs/Extensions/theme/)
- Soporta multiples pestañas
- Lo más importante es que es un software de código abierto (OSS)!

Files se encuentra actualmente en desarrollo. Puedes dar tus sugerencias y comentarios a nuestra página de [Discusiones](https://github.com/softeng/Files/discussions/). Si te sientes cómodo escribiendo código usando Typescript y Rust, te recomendamos que [contribuyas a este proyecto](https://Files.space/community/Contributing/).
