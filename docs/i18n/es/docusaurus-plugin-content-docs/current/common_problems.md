# Problemas comunes

**Nota: Para problemas comunes durante la instalación, por favor abra [Aquí](/docs/install/#common-problems)**

<details>
<summary>

### Abrir la carpeta como `Documentos`, `Escritorio`, `Descargas` hace que Files falle

</summary>

Desactivar la configuración [`Extraer el icono del archivo exe y hacerlo como vista previa`](/docs/guides/setting/#extract-exe-file-icon-and-make-it-a-preview).

Además, asegúrate de que Windows Defender no esté bloqueando el acceso de Files a tus documentos.

</details>

<details>
<summary>

### Files es inestable después de instalarlo

</summary>

Simplemente reinicie, Files se arreglará solo, si no lo hace, por favor dirija un problema [aquí](https://github.com/softeng/Files/issues/new).

</details>
