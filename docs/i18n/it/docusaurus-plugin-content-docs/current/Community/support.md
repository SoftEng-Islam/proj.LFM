# Supporto

Files è un progetto open-source al quale puoi liberamente unirti e cercare supporto 😊.

In questa pagina, abbiamo elencato alcune comunità/forum a cui puoi partecipare per cercare supporto o aiutare altre persone.

Prima di partecipare alle comunità di Files, si prega di leggere il nostro [Codice di condotta](/docs/community/CODE_OF_CONDUCT/).

## Problemi

Usiamo la sezione problemi di GitHub per monitorare i bug pubblici. Assicurati che la tua descrizione sia chiara e abbia istruzioni sufficienti per poter riprodurre il problema. Segnala un bug aprendo una nuova segnalazione [qui](https://github.com/softeng/Files/issues/new).

## Discussioni di GitHub

Le discussioni di GitHub sono usate per molteplici scopi, come:

1. Porre domande
2. Fare richieste di funzionalità e condividere idee
3. Chat su Files
4. Mostra e racconta: Realizzare temi/plugin personalizzati per Files e mostrarli agli altri!

### Richieste Di Funzionalità

Usiamo la [Sezione Discussioni di GitHub](https://github.com/softeng/Files/discussion) e [Problemi di GitHub](https://github.com/softeng/Files/issues) per tenere traccia delle idee dagli utenti. Suggerisci una nuova funzionalità [qui](https://github.com/softeng/Files/discussions/new)! Le grandi richieste di funzionalità hanno solitamente:

- Un rapido riepilogo dell'idea.
- Che cosa e perché si voleva aggiungere la caratteristica specifica.
- Riferimenti aggiuntivi come immagini, link di risorse sulla funzionalità, ecc.

### Aiuto

Puoi chiedere aiuto usando la [Sezione Discussioni](https://github.com/softeng/Files/discussions) o il [Canale Discord](https://discord.gg/kK7rwxPt).

:::note
Ricordati di scegliere la categoria di discussione come Q&A in modo che la tua domanda venga pubblicata con le risposte abilitate.
:::
