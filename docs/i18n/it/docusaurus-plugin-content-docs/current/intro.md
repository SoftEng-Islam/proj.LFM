# Files

![Demo](/img/docs/themed-Files.webp)

## Riepilogo

Benvenuto in Files, Un File EFiles Gratuito e Open Source (FOSS).

Files è un moderno file eFiles costruito da zero per essere completamente personalizzabile per soddisfare le esigenze del 2022. Inoltre, Files è un'applicazione multi-piattaforma alimentata dal web che viene mantenuto utilizzando il framework [Tauri](https://tauri.studio) in cui è possibile eseguire Files su Windows, MacOS, o Linux senza avere molti problemi. Alcune caratteristiche di Files in sintesi sono:

- Ha un aspetto moderno
- Semplice da usare
- [Multipiattaforma](https://Files.space/)
- [Anteprima file](https://Files.space/docs/guides/operation/#preview-file), anche per i video!
- [Personalizzabile](https://Files.space/docs/Extensions/theme/)
- Supporta schede multiple
- Soprattutto, si tratta di un software Open Source (OSS)!

Files è attualmente in fase di forte sviluppo. Puoi dare i tuoi suggerimenti e feedback sulla nostra sezione [Discussioni](https://github.com/softeng/Files/discussions/). Se ti senti a tuo agio nella scrittura del codice utilizzando Typescript e Rust, ti invitiamo vivamente a [contribuire a questo progetto](https://Files.space/community/Contributing/).
