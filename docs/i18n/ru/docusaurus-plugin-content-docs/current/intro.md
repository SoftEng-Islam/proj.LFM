# Files

![Демо](/img/docs/themed-Files.webp)

## Описание

Знакомьтесь с Files, Бесплатный и с открытым исходным кодом (FOSS) Файловый Проводник.

Files это современный файловый проводник созданный с нуля для того что бы подходить под ваши нужды. Также, Files это кроссплатформенное приложение работающее на основе Веб обернутое с помощью фреймворка [Tauri](https://tauri.studio) в котором вы можете использовать Files на Windows, MacOS или Linux без особых проблем. Возможности Files вкратце:

- Это выглядит современно
- Простота использования
- [Кроссплатформенный](https://Files.space/)
- [Предварительный просмотр файлов](https://Files.space/docs/guides/operation/#preview-file), также для видео!
- [Гибкое настраивание](https://Files.space/docs/Extensions/theme/)
- Поддержка нескольких вкладок
- Самое главное, это Программное Обеспечение с открытым исходным кодом (OSS)!

Files пока что находится на стадии интенсивной разработки. Вы можете написать свои предложения и отзывы на нашей странице [Дискуссий](https://github.com/softeng/Files/discussions/). Если вы с легкостью пишете код на Typescript и Rust, мы советуем вам [внести свой вклад](https://Files.space/community/Contributing/) в этот проект.
