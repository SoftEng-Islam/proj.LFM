# Our Roadmap To make a perfect File Manager for Linux Systems

## features needed

1. Multitask with tabs
   1. Avoid multiple windows and keep your desktop clutter-free with tabs.
2. Dual pane
   1. View and manage two folders side by side with Dual Pane feature.
3. Tag files and folders
   1. Organize and sort your files and folders with colored tags.
4. Column view
   1. Quickly navigate through different levels of the file system using the column layout.
5. View and edit archives
   1. Create and extract archives including zip, WinRar, and 7zip.
6. Seamless cloud integration
   1. Built-in support for cloud drives such as OneDrive, Google Drive and ICloud.
7. Preview pane
   1. Preview photos, videos, and documents without opening them.
8. QuickLook & SeerPro support
   1. Preview Office files, documents, and other file types by pressing the space bar. This feature requires installing QuickLook or SeerPro.
9. Git integration
   1. Easily manage your Git projects. create new branches, switch between them, and sync your changes - all without leaving the Files manager.
10. Hashes
    1. View and compare file hashes from the properties window.
11. Command Palette
    1. Quickly access commands, features, and settings from the Command Palette.
12. Remap key bindings
    1. Streamline your workflow by creating custom key bindings.
13. Toolbar Customization
    1. Personalize the toolbar by adding or removing buttons from the list of available actions.
