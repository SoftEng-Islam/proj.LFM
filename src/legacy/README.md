# Legacy Code

- The repository is being reshaped around Vue, TypeScript, Tailwind CSS, Sass, and Tauri.
- The old frontend entry and directory layout did not match that stack.
- Keeping it here avoids deleting working logic while the new feature-based frontend is built.

Treat this folder as migration source material, not as the active app entry.
