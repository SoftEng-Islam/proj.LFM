# LFM Project Architecture

## Overview

LFM is a Linux-first desktop file manager built with:

- Vue
- Tauri
- TypeScript

## Recommended Structure

```txt
src-ui/
├── assets/
├── components/
├── composables/
├── pages/
├── services/
├── stores/
├── styles/
├── types/
├── utils/
```

## Performance

Prefer:

- async operations
- lazy loading
- virtualization
- caching
