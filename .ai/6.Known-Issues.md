## 10. [] Preview & Multimedia System (Research/Experimental)

### 10.1 Videos Support (Direct Rust FFI to libmpv)

Also we will use it to run Audio with vue-audio-visual for effects audio visualization

Tauri + libmpv Integration Guide For Linux File Manager (Vue + Tauri + Rust)
This document explains how to integrate `tauri-plugin-libmpv` into the application.

Plugins:

- tauri-plugin-libmpv
  - <https://docs.rs/tauri-plugin-libmpv/latest/>.
- ffmpeg-next
  - <https://docs.rs/ffmpeg-next/latest/ffmpeg_next/>
  - <https://crates.io/crates/ffmpeg-next>
- nom-exif Metadata Probing (ffprobe replacement)
  - <https://docs.rs/nom-exif/latest/nom_exif/>

#### Videos Goal

- Better native integration
- Lower resource usage
- Better codec support
- Use `libmpv` as the native video/audio engine inside the Tauri application.

#### Videos Tasks

- Add ffmpeg-next to the project
- (zero-dependency) You have to force the Rust compiler to statically link FFmpeg inside the binary file. This embeds the required parts of FFmpeg directly into single src-tauri executable. do this by enabling the static feature flag in Cargo.toml:
  - `ffmpeg-next = { version = "...", features = ["static"] }`

Architecture:

```text
Vue UI
   ↓
Tauri IPC
   ↓
Rust Backend
   ↓
tauri-plugin-libmpv
   ↓
libmpv
   ↓
Native GPU Playback
```

#### The Result

- No GStreamer dependencies.
- No user-facing setup scripts.
- No complex compilation setups on your development machine.
- The app will run exactly like a Windows app—completely self-contained within its installation bundle.
