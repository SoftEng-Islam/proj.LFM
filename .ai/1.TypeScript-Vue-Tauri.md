# TypeScript, Vue, and Tauri Rules

## TypeScript

- Use strict typing.
- Avoid `any` unless necessary.
- Prefer interfaces and explicit types.

## Vue

- Use Composition API only.
- Prefer composables for reusable logic.
- Keep business logic outside templates.
- Avoid deeply nested logic.
- Stick to standard Vue <template> tags for a faster UI layer.

## Tauri

Frontend:

- UI
- rendering
- interaction

Backend:

- filesystem
- system integration
- heavy processing
