## Available Scripts

In this project directory, you can run:

### `npm start`

Runs the theme in development mode. This will automatically opens Files with your theme being loaded in development mode.

The theme will be automatically reloaded when you make changes to the theme files.

### `npm run build`

Build and package the theme for production to the `dist/themes.xtension` file.

### `npm run Files:install`

Install the theme in Files.
